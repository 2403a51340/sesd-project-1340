Defense-In-Depth

Cryptographic Trust & Architecture

Built strictly adhering to modern cybersecurity standards, data privacy mandates, and enterprise availability requirements.

bcrypt Password Hashing

All institutional and admin credentials utilize high-iteration salted bcrypt hashes, preventing brute-force and dictionary exploits.

Intelligent Rate Limiting

Automated rate limiting across auth and verification endpoints blocks malicious scraping bots, credential stuffing, and DDoS spikes.

Secure HTTP-Only Cookies

Session tokens utilize HTTP-only, SameSite=Lax flags, completely shielding authentication state from client-side XSS tampering.

PII Privacy Masking

Student personal email and contact identifiers are strictly masked on public verification lookups to ensure compliance with privacy laws.

Helmet Security Headers

Strict Content Security Policy (CSP), X-Frame-Options, and HSTS headers enforced across all incoming HTTP traffic.

Conflict & Anomaly Auditing

Every anomalous query or duplicate ID attempt automatically writes to an immutable administrative security ledger for human audit.
